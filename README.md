DELTA SINGULAR — Kryoneri

Special Building — Kryoneri, Attica, Greece

Architect: Xenophon Stefanidis

This repository presents documentation concerning the DELTA PLIROFORIKI S.A. project in Kryoneri, Attica.

Project

According to the confirmation issued by AKTOR S.A. on 25 July 2007, Xenophon Stefanidis provided:

architectural pre-design and detail design

site supervision

interior pre-design and detail design

supervision of the project

The project involved the remodelling and extension of an existing industrial building into a high-tech, maximum-security facility.

The documented facilities included intelligent printing, a bank disaster room, credit-card embossing, a call center for disabled employees, restaurant and kitchen facilities, kindergarten, infirmary, physical therapy and gym areas.

Scale

The AKTOR confirmation states:

Approximate total project value: €13,000,000

Approximate architectural design component: €7,000,000

Approximate overall covered area: 10,000 m²

Project launch: 2000–2001
